# 删除会话

在左侧会话列表中对任意会话点右键，选择“删除会话…”。

## 行为

1. 弹出确认框，说明 DSH 运行期间无法安全删除会话文件。
2. 确认后，会话立即从主列表隐藏（进入“已归档”），并写入删除队列。
3. 下次启动 DSH 时，插件在 Host 启动阶段处理队列：
   - 删除该会话的存储目录（JSONL 日志及附属文件）；
   - 删除 `storages/session_projcache/sessions/` 下对应的投影缓存；
   - 从工作区记录中移除该会话，并从归档集合中清除它的 id；
   - 从队列中移除该条目。

## 队列

队列文件位于 DSH Home：

```
<DSH_HOME>/session-delete/pending.json
```

格式为 `{ "version": 1, "sessions": { "<sessionId>": { "queuedAt": 0, "title": "" } } }`。

每条记录带 `queuedAt`。插件只处理 `queuedAt` 早于当前进程启动时间的条目；在本次运行中刚排队的会话不会被同一进程删除，必须等到下一次启动。插件在一次进程生命周期内只扫描队列一次。

如果队列文件损坏，会被重命名为 `pending.json.corrupt-<timestamp>`，不会静默覆盖。

## 说明

- 运行中的 DSH 不会在请求时删除任何文件，只做隐藏和排队。
- 如果会话正在执行任务，归档会先停止其任务，再隐藏。
- 删除当前打开的会话时，界面会自动切回新会话。
- 真正删除前，会话仍可在“已归档”中找到；重启后不再出现。
- 待删除期间改变主意：先退出 DSH，再从 `pending.json` 中删除对应条目；该会话不会被删除，仍可在“已归档”中取消归档。
